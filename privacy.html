2. 다루는 정보

  • 채널 식별 정보 — 채널 ID, 채널명, 프로필·배너 이미지 주소
  • 영상 지표 — 이 앱으로 올린 영상의 조회수·좋아요 수·댓글 수
  • 접근 토큰 — 구글이 발급한 리프레시 토큰

이름·이메일·주소·결제 정보는 다루지 않습니다. 시청자 개인정보에는 접근하지 않습니다.

3. 어디에 저장하나

운영자의 컴퓨터에만 저장됩니다. 별도의 서버가 없고, 외부로 전송하지 않습니다. 토큰 파일은 소유자만 읽을 수 있도록 권한을 제한(600)해 보관합니다.

4. 어디에 쓰나

  • 승인받은 채널에 영상을 올리는 데
  • 올린 영상이 심사를 통과했는지 확인하는 데
  • 조회수 흐름을 보고 다음 업로드 편수를 정하는 데
  • 업로드 기록을 남겨 나중에 소명할 수 있게 하는 데

5. 제3자 제공

제공하지 않습니다. 판매·공유·광고·분석 목적의 활용이 일절 없습니다. 데이터는 구글 API와 운영자의 컴퓨터 사이에서만 오갑니다.

6. 보관 기간과 삭제

  • 채널 주인이 승인을 철회하면 그 즉시 접근이 끊깁니다
  • 철회는 구글 계정 → 보안 → 타사 앱 에서 언제든 가능합니다
  • 업무가 끝나면 해당 채널의 토큰과 저장된 정보를 지웁니다

7. 제한적 사용 준수

이 앱이 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책을 따르며, 제한적 사용(Limited Use) 요건을 지킵니다.

English Summary

미니미쇼픽업로더 is a personal tool used by a delegated manager to upload short-form videos to YouTube channels with the channel owner's explicit consent.

  • Scopes requested: youtube.upload (to upload videos) and youtube.readonly (to identify the target channel and read view/like/comment counts of videos uploaded by this tool), and youtube (to switch a reviewed private upload to public).
  • Data handled: channel ID and title, public metrics of uploaded videos, and the OAuth refresh token.
  • Storage: stored only on the operator's local computer. There is no server. Token files are permission-restricted to the owner.
  • Sharing: data is never sold, shared with third parties, or used for advertising or analytics.
  • Deletion: access ends immediately when the channel owner revokes it at Google Account → Security → Third-party apps.
  • Limited Use: use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
